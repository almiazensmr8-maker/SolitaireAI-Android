# Solitaire AI V3 — مشروع أندرويد مستقل

## ماذا يحتوي؟
- محرك Klondike Solitaire مكتوب بـ Kotlin.
- بحث محدود متعدد الخطوات في `AdvancedSolver.kt`.
- واجهة مستقلة لاختبار المحرك.
- لوحة عائمة قابلة للسحب، مع أزرار تشغيل/إيقاف واختيار سريع/متوازن/عميق.
- طلب صلاحية Android للظهور فوق التطبيقات الأخرى.

## حدود مهمة
اللوحة العائمة هي واجهة تحكم فقط. لا تقرأ شاشة Jawaker، ولا تستخرج أوراقها، ولا تنفّذ نقرات داخلها، ولا تتصل بحساب Jawaker. اختيار مستوى القوة يغيّر إعدادات البحث في التطبيق المستقل: سريع (4 خطوات/250 عقدة/80ms)، متوازن (10 خطوات/3500 عقدة/700ms)، عميق (18 خطوة/12000 عقدة/1800ms). هذه الحدود ميزانيات بحث وليست ضماناً للفوز. لا تصل إعدادات الواجهة إلى لعبة جواكر ولا تجعل المحرك يقرأ حالتها.

لا يوجد ضمان للفوز في كل توزيع. يجب قياس معدل الفوز باختبارات منفصلة قبل وصف المحرك بأنه قوي تنافسياً.

## الربط البرمجي
- المحرك: `app/src/main/java/com/ammar/solitaireai/AdvancedSolver.kt`
- قواعد اللعبة: `CardEngine.kt`
- الواجهة العائمة: `FloatingControlService.kt`
- إعدادات القوة المشتركة: `EngineSettings.kt`
- نقطة التشغيل: `MainActivity.kt`

## البناء
هذا أرشيف مصدر Android Studio، وليس APK مبنياً. يلزم Android SDK وGradle وبيئة Kotlin/Android لبناء APK. MT Manager يستطيع عرض وتعديل ملفات APK/DEX/Smali، لكنه لا يحوّل ملفات Kotlin إلى DEX بمفرده.
